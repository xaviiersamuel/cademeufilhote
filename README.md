# 🐶 Cadê meu filhotinho?

> **Projeto de Conclusão de Curso (TCC)** > Curso Técnico em Informática — IFRJ Campus Arraial do Cabo.

O **Cadê meu filhotinho?** é uma plataforma web full-stack desenvolvida com o objetivo de conectar pessoas para ajudar na localização de animais perdidos e incentivar a adoção responsável na Região dos Lagos. O sistema combina uma interface intuitiva com artigos informativos de conscientização sobre saúde e bem-estar animal.

---

## 🚀 Funcionalidades Principais

- **Feed Dinâmico de Pets:** Listagem cronológica de publicações sobre animais perdidos ou disponíveis para adoção.
- **Modo Visitante:** Permite a navegação completa pelas abas informativas e visualização do feed sem a obrigatoriedade de cadastro.
- **Autenticação Segura:** Sistema de cadastro e login de usuários com criptografia de senhas no back-end.
- **Upload Interativo com Recorte:** Ferramenta front-end em Canvas JavaScript que permite ao usuário arrastar, dar zoom e ajustar a foto do pet antes da publicação.
- **Gerenciamento de Postagens (CRUD):** Usuários logados podem publicar novos anúncios e excluir suas próprias postagens de forma restrita e segura.
- **Abas de Conscientização:** Páginas educativas completas sobre:
  - 🦠 Zoonoses Urbanas
  - 💉 Calendário de Vacinação
  - 💗 Manual de Adoção Responsável
  - 🐶 Importância da Castração
  - 🫂 Suporte Emocional (Luto Interespécies)

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias modernas de desenvolvimento web, divididas entre:

- **Front-End:**
  - HTML5 & CSS3 (Design Responsivo e Customizado)
  - JavaScript (Manipulação de DOM, requisições assíncronas e manipulação de imagem via Canvas)
  - Bootstrap 5 (Framework para modais e componentes estruturais)
- **Back-End:**
  - PHP (Gerenciamento de rotas, controle de sessões e processamento de dados)
- **Banco de Dados:**
  - MySQL (Armazenamento relacional de usuários e postagens)
